## How to Run the Projects

The commands below are general examples. The exact setup may vary depending on each project's implementation.

| Project Type | Instructions |
|---|---|
| HTML, CSS, and JavaScript | Open `index.html` in a web browser. |
| Node.js | Run `npm install`, followed by the start command defined in `package.json`. |
| FastAPI | Install dependencies with `pip install -r requirements.txt`, then run `uvicorn main:app --reload` if the application uses `main.py` and exposes `app`. |
| Docker | Build the image with `docker build -t app .` and run it using the appropriate port configuration. |

Refer to the individual project's documentation for specific requirements and setup instructions.

## Development Practices

Throughout the internship, I aim to follow professional software development practices:

- **Version Control:** Use Git and GitHub to track changes and manage project history.
- **Branching Strategy:** Create separate branches for individual tasks or features.
- **Meaningful Commits:** Write clear commit messages, such as `feat: add bento gallery layout` and `fix: adjust clock hand pivot`.
- **Documentation:** Include clear setup instructions and explanations for each project.
- **Code Quality:** Prioritize readability, maintainability, semantic HTML, and reusable code.
- **Responsive Design:** Ensure web interfaces work across different screen sizes.
- **Security:** Keep credentials, API keys, and environment files out of version control.
- **Collaboration:** Use Pull Requests and code reviews to improve implementation quality.
